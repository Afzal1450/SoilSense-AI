# Soil-Type-Classification for Crops Suggestion 🌳🌲🎄🎋🌴

### Overview
For this project, a deep learning model is trained using two combined datasets featuring images across four different soil types: **Alluvial**, **Black**, **Clay**, and **Red**. 

Based on the classified soil type, suitable crop suggestions are generated to help optimize crop yield.
